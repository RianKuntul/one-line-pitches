Entry for the make.fun competition "A Day of One-Line Pitches"
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

The program writes a single one-line pitch (at most 240 characters) to
`/output/entry.txt` — a sentence that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

Run with Node:

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to override the output directory (default `/output`).
