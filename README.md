Entry for the make.fun A Day of One-Line Pitches — one sentence, 240 characters max, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## Run it

```sh
node main.ts
```

Writes the pitch to `/output/entry.txt` (override the output directory with `MAKEFUN_OUTPUT_DIR`).

## The entry

> You describe the app over coffee; an AI agent builds it while you finish the cup — your idea, working software, before lunch, no coding degree required.
